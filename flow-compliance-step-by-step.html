Web — WHAT it says (live)

Query: site:echa.europa.eu "SVHC candidate list" n-Hexane BPAF Feb 2026
Result: n-Hexane CAS 110-54-3, BPAF group (9 substances), threshold >0.1% w/w, deadline Aug 4 2026, 253 SVHCs total.

Query: H&M Group RSL 2026 chemical restrictions
Result: H&M n-Hexane limit = 10 ppm (0.001% w/w) — 100× stricter than REACH 0.1% regulatory floor.

Query: Primark RSL ZDHC MRSL alignment
Result: Primark tracks via ZDHC MRSL — adhesives in scope, BPAF monitoring pending.
Key distinction: KB says "check buyer's published RSL for n-Hexane limit" — it does NOT store "H&M = 10 ppm". That value changes and is fetched live via web search. Penalty cases are KB-GAP — not yet built.

Link 到 WIP 节点：Production Stage × Compliance Action
KB: COMBO product type → WIP stage mapping

Each COMBO's product type maps to a production stage. At each stage, a different compliance action is required.

WIP Stage 1 Sewing / Assembly Adhesive application (denim). Coating treatment (home textile). Audit formulations now. Re-test decisions made at this stage.
WIP Stage 2 Finishing / Wash Stonewash, laser-finish, foam coating use n-Hexane. Confirm SVHC content before finishing. If >0.1% w/w → hold production, test first.
WIP Stage 3 QC / Pre-Ship Lab results should be back (14–21 days). If PASS → release. If FAIL → cannot ship, escalate to Step 9.
WIP Stage 4 At Port / In-Transit If SCIP not yet submitted and goods contain >0.1% w/w SVHC → customs hold risk. Submit SCIP before arrival.
COMBO-005: denim → finishing stage highest risk (n-Hexane in adhesives) COMBO-009: home-textile → coating stage highest risk (BPAF in resins) ⚠️ KB-GAP: No dedicated WIP × SVHC risk map file yet. Next iteration.
WIP × Compliance action: Stage 1–2: Re-test submission, formula audit (14–21 day production hold). Stage 3: results determine ship or hold — cashflow gap starts here. Stage 4: SCIP submission + customs hold risk.
